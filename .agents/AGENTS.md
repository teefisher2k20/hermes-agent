# Workspace Rules & AI Client Recommendations

## Summary Recommendation
- **For daily desktop chatting with Ollama / OpenAI / Claude**: Use Chatbox for simplicity, or Jan if you want everything packaged together.
- **For chatting with your PDFs, codebase, or notes**: Use AnythingLLM.
- **For sharing an AI instance with a team or self-hosting on a home server**: Use Open WebUI.
- **For automated task execution and complex agentic workflows**: Use Hermes Agent.
